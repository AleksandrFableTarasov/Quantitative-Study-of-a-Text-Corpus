# Quantitative-Study-of-a-Text-Corpus
## Стек

pandas, numpy, matplotlib, seaborn, nltk, pymorphy3, wordcloud, scikit-learn, xgboost, scipy

## Что сделано

1. Загружено 16 подкорпусов (автор + жанр)
2. Очистка: нижний регистр, удаление пунктуации и стоп-слов, лемматизация
3. Анализ: длина предложений, частотность слов, LDA, близость авторов, TTR, уникальные слова, части речи, динамика по годам, эмоциональная окраска
4. Визуализации: облака слов, тепловые карты, дендрограмма
5. ML: классификация жанра (Random Forest), классификация автора (XGBoost), регрессия года (Linear Regression / Random Forest)

## Выводы

1. Поэзия и проза различаются по лексике и тематике
2. Жанр — главный фактор близости: прозаики к прозаикам, поэты к поэтам
3. Некрасов выделяется социально-крестьянской тематикой
4. Публицистика Толстого стоит особняком
5. Проза Блока лексически разнообразнее его стихов
6. TTR обратно пропорционален объёму текста
7. Random Forest надёжно различает прозу и поэзию (accuracy 0.95), публицистика хуже из-за малого объёма
8. XGBoost хорошо определяет авторов (accuracy 0.81); редкие авторы нуждаются в большем количестве текстов
9. Линейная регрессия плохо предсказывает год (R^2 0.13), Random Forest — лучше (R^2 0.56) — есть нелинейные зависимости
10. pymorphy3 вероятно неверно определяет часть речи для слова «мочь»

## Что можно улучшить

1. Увеличить количество публицистических текстов
2. Добавить данные для редких авторов или исключить их из анализа
3. Добавить датировку всех произведений
4. Для LDA удалять имена персонажей (сложно автоматизировать) и увеличить объём корпусов
5. Расширить выборку: добавить авторов XVIII и XX века
6. Применить BERT / transformers вместо TF-IDF
